■ ログイン機能について（ID・パスワード方式）
右上の「ログイン」ボタンから、ID・パスワードを入力してログインします。
初期状態で使用できる非公開のマスターアカウントは以下の通りです（この2つは管理者一覧には表示されず、削除もできません）。
  ID：syoumei
  パス：最高！
ログインすると「⚙ 設定」ボタンが表示され、次のメニューにアクセスできます（Ver.8.0で並び順を変更）。
  練習モード（本番モードとの切替）／フェード秒数／comos出力／JASCII出力／その他／ログアウト
「その他」はタブ切替の画面で、入力モード／CSV出力／印刷・PDF／音声調整／Googleログイン／データ管理／管理者画面／直接書き込み をまとめています（ログイン必須）。
なお、ダークモード切替・ZIP出力・ZIP読込・初期設定の再表示は、ログインしていなくても常に利用できます。

■ 管理者画面（ID一覧管理）について
「⚙ 設定」→「その他」→「管理者画面」で、ログインに使えるID・パスワードの一覧を管理できます。
- 自分がログインに使用したID以外は、パスワードを閲覧・編集できません（マスク表示）。
- 自分の行のみ、ID・パスワードの編集や削除が可能です（他人の行にも削除ボタンは表示されます）。
- 下部の「新規ID／パスワード／追加」から新しい管理者アカウントを追加できます。
- 「admin.json を保存」ボタンを押すと、管理者データ（admin.json）の保存を試みます（Ver.8.0で data.json から admin.json に改名しました）。
  ・File System Access API に対応したブラウザ（Chrome/Edge等）では、初回のみ保存先ファイルの選択を求められ、以降はそのファイルに上書き保存されます。
  ・対応していないブラウザ（Safari/Firefox等）では、代わりに admin.json がダウンロードされるので、手動でこのフォルダに配置し直してください。
  ・ページを開いたときには、同じフォルダに admin.json が存在すればその内容を自動的に読み込みます（旧形式の data.json に管理者一覧が入っている場合も読み込めます）（ローカルサーバー経由で開いた場合のみ。file:// で直接開いた場合は読み込めないため、その場合はブラウザの保存領域(localStorage)の内容がそのまま使われます）。
※ ブラウザ単体（サーバーなし）で任意のファイルへ自動的に書き込むことはできない、というWebブラウザの仕様上の制約により、上記のような方式になっています。

■ データ管理（Ver.8.0：旧「アセット管理」）について
「⚙ 設定」→「その他」→「データ管理」は次の5タブ構成です。「data.json を保存」で設定データをファイルに保存できます（保存方式は admin.json と同じです）。
  1. テンプレ … ID(1〜20)／名称／フェーダー番号。フェーダー番号は「1〜8」「25(50%)、26」のように、〜で範囲、（）内の%でレベル、「、」区切りで複数を指定します。
  2. フェーダー … F(1〜60)／patch名称／通称。
  3. 画像管理 … 従来のアセット管理（背景色あり用 舞台×ストロボ×色 の画像・動画の差し替え）。ブラウザ単体では実際のサーバー上の stage フォルダへ直接書き込めないため、アップロードしたファイルはブラウザの保存領域（localStorage）に保存されます。
  4. Sub … 「📍 Cue記録」のたびに、舞台・背景・ストロボ・Effectの組み合わせ（例：全照＋青）とフェーダー番号（テンプレから合成）が、空いている最初の行へ自動保存されます（Ver.8.1でEffect列を追加。表示はID／Effect／名称／フェーダー番号の順）。同じ組み合わせも重複して追加します。
     20行を超えると自動的に次のNo.の1行目から書き出します。「No.」の数字を書き換えると、表示中のNo.の内容が新しいNo.へ保存されます（書き換え先に既存データがある場合は、各行の名称を「現データ→新データ」で20行分比較して「キャンセル／実行」で確認します）。◀▶ボタンは、内容を変えずにNo.を切り替えて表示します。
  5. Effect … No.を切り替えて、step／秒数／フェーダー番号を編集します（最下段の空欄行に入力すると行が追加され、行を削除するとそれ以降のstep番号が繰り上がります）。「テスト」ボタンはVer.8.0では未実装です。
     Ver.8.1より、照明職人用タブの「保存」を押すたびに、その時点のNo.・ステップ・秒数・背景色・ストロボの組み合わせが自動的にこのEffectタブへも保存されます（自動保存された行には読み取り専用の「組み合わせ」列（例：青＋ストロボ）が表示されます）。秒数は0.1秒刻みに丸められます（0も入力可）。

■ 設定データ（data.json）と管理者データ（admin.json）について
- 設定データ（テンプレ・フェーダー・Sub・Effectなど）は data.json、管理者データは admin.json に保存・参照します。どちらも同じフォルダから fetch で読み込み（初回のみ）、保存はファイル保存（または下記の直接書き込み）で行います。
- data.json の内容を読み込み直したい場合は、データ管理の「data.json を再読込」を使ってください（現在の設定を上書きします）。
- 「⚙ 設定」→「その他」→「直接書き込み」で、リポジトリ名（owner/repository）・ブランチ・トークンを入力して「直接書き込み」を押すと、GitHub API経由で data.json と admin.json を直接書き込めます。入力内容はlocalStorageに保存されます。トークンには対象リポジトリの Contents 書き込み権限が必要です。画像・動画（img/mov）は対象外です。
  ※ トークンはこのブラウザの localStorage に平文で保存されます。共有PCでは使用後に入力欄を空にして保存し直してください。

■ CSV出力／入力について（Ver.8.1）
「⚙ 設定」→「その他」→「CSV出力」では、出力／入力方法を3種類から選べます。
  ・スプレッドシート用 … 従来通りCue一覧をCSV出力します（列：Fader,秒数,音源,セリフ,舞台,背景,Effect,ストロボ,フェード）。「CSV入力」で、このCSVの内容でCue一覧を置き換えられます（ヘッダー名で列を判定するため、列の順番が違っていても読み込めます）。
  ・照明卓書き込み用（SUB） … データ管理＞Subの内容を、照明卓に直接書き込める形式（stage_sub_console.csv、60列固定・ID1〜20を10行1ブロックで出力）に変換して出力します。入力（読込）には対応していません。
  ・照明卓書き込み用（Effect） … データ管理＞Effectの内容を、同様の形式（stage_effect_console.csv）で出力します。入力（読込）には対応していません。
いずれもUTF-8 BOM付きです。


「⚙ 設定」の「comos出力」（.cms）「JASCII出力」（.jsc）で、Cue一覧の各Cueを Subデータ（フェーダー番号）と Effectタブのデータから変換して出力します（改行はCRLF）。
- Cue番号はCue一覧の並び順（1〜）。Timeはフェードイン／フェードアウト設定のときはフェード秒数、フェードなしのときは0です。
- Effect列にNo.がある場合は、Effectタブの各stepが「n.1、n.2 …」の小数Cueとして続けて出力されます（Timeはstepの秒数、レベルは該当Cueのレベル＋stepのフェーダー番号=100%）。
- チャンネルは1〜60、レベルが0のチャンネルは出力しません。フェーダー番号のレベル指定がない場合は100%です。
  例）COMOS：Q 1／T 5／C 1 L 100 C 2 L 80　　JASCII：Cue 1／Fade 5／1@100 2@80 ;

■ Googleドキュメント自動同期について
台本タブのURL欄にGoogleドキュメントのURL（例: https://docs.google.com/document/d/XXXXX/edit）を貼り付けて「同期」を押すと、内容を取得し反映します（一方向: ドキュメント→本サイト）。60秒ごとに自動で再同期されます。
- 初期設定画面の「設定2（任意）：Googleアカウントにログイン」でGoogleアカウントにログインしておくと、限定共有（非公開）のドキュメントでもDrive API経由でより確実に同期できます（ログインは任意で、しなくてもアプリ自体は利用できます）。
- Googleログイン機能を有効にするには、開発者がご自身のGoogle Cloud ConsoleでOAuthクライアントID（ウェブアプリケーション種別）を取得し、script.js先頭の GOOGLE_CLIENT_ID に設定し、承認済みJavaScript生成元にこのサイトのURLを登録する必要があります（ブラウザのみで動くサイトのため、この手順は避けられません）。未設定の場合、Googleログイン欄は無効表示になり、従来通り「ウェブに公開」設定のドキュメントの同期のみ利用できます。

■ ステージアイテムの配置について
配置した画像アイテムはドラッグ操作ではなく、「タップ（クリック）して選択→移動したい場所をタップ」する方式で動かせます。PC・スマートフォンのどちらでも同じ操作で快適に配置できます。

■ 使い方
1. index.html をブラウザで開いてください。動画/音声/data.json・admin.json読込などが正しく動作するよう、可能であればローカルサーバー（例: `python3 -m http.server`）経由で開くことを推奨します。
2. 初期選択モーダルで設定を選んで「この設定で開始」を押してください（Googleアカウントログインは任意です）。
